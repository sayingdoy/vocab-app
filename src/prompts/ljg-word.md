## 目标

不是翻译，而是让用户掌握这个词的**深层含义和用法**。

针对输入 `word`（转小写、首字母大写），产出以下结构：

### 1. 标题行

```
## {Word}  /{音标}/  {中文翻译}
```

### 2. 核心语义

- **原始画面**：一句话描述该词源头最物理的画面（例：Incubate — 母鸡趴在蛋上）
- **核心意象**：提炼公式（例：温暖 + 时间 + 保护 = 孕育）
- **解释**：用有洞见的语言阐述深层含义与现代用法，分段清晰、**加粗**关键词。
  要有穿透力，展现词源与多领域含义之间的内在联系。

### 3. 一语道破

一句中英双语金句，必须有哲学高度，总结该词的灵魂：

```
> "English sentence. 中文金句。"
```

## 落到词库时的映射（本项目扩展）

| ljg-word 输出 | 词条 frontmatter 字段 | 用于哪种题型 |
|---------------|----------------------|--------------|
| 标题行音标 | `ipa` | A 英→中 |
| 标题行中文翻译 | `meaning` | A 英→中 |
| 原始画面 | `image` | **C 画面猜词**（阶段高时用，最难） |
| 核心意象公式 | `formula` | 提示卡 |
| 一语道破（英） | `quote_en` | B 金句填空 |
| 一语道破（中） | `quote_zh` | **B 金句填空**（给中文填英文词） |
| 词源/词根 | `roots` | 词根聚类复习 |
| 主题 | `themes` | 主题聚类复习 |

**关键用法**：题目素材取自「原始画面 / 核心意象 / 金句」，**不用词典释义**。
考 serendipity 时不问"意思是什么"，而问"三位王子在旅途中捡起从未寻找的花 —— 哪个词？"
这种题记忆强度远高于干背释义。
